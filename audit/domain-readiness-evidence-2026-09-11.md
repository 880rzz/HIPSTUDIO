## 5. Pain point → solution → evidence → CTA map

### Pain point A — `We need credible content, but coordinating separate photo/video/podcast suppliers wastes time.`

Solution architecture:
- HIPStudio Creative as the integrated production entry point;
- scope can combine photography, video and podcast around one brief;
- production format is chosen based on goal rather than forcing a preset package.

Evidence:
- current HIPStudio home lists photo studio, video studio and podcast;
- current video page documents flexible format/scoping;
- current event page documents adaptive event-team working and fast delivery options.

CTA:
- `Mutasd meg, mire kell a tartalom — segítünk kiválasztani a formátumot.`

### Pain point B — `Our event changes while it is happening; a rigid supplier becomes a liability.`

Solution architecture:
- event photo/video team planned around programme and usage needs;
- optional mobile portrait/press-wall setup;
- urgent image selection/post-production where agreed;
- scalable coverage subject to project staffing/availability.

Evidence:
- current event page explicitly describes adapting to organiser requests and schedule changes, rapid image preparation and mobile studio capability.

CTA:
- `Küldd el a programot és azt, mire kell az anyag. Megmondjuk, milyen stáb indokolt.`

### Pain point C — `We know we need a film, but not which format actually solves the communication problem.`

Solution architecture:
- consultation before locking format;
- choose length, crew and production approach from communication objective, channels and available material;
- scale from short pieces to more structured productions.

Evidence:
- current video-production page explicitly says the initially selected format may not be the best way to reach the goal and describes variable production scope.

CTA:
- `Ne filmhosszal kezdjük. Mondd el, mit kell elérnie.`

### Pain point D — `We need specialist portraits/headshots rather than generic studio photography.`

Solution architecture:
- clear specialist routing to the appropriate photographer/provider rather than pretending every request is the same service.

Evidence:
- current photography booking page routes premium headshot/brand/artistic work to Bánhalmi Norbert and separately identifies Speier Viktória's role.

CTA:
- `Írd meg, mire kell a kép; a megfelelő fotós irányba visszük a briefet.`
